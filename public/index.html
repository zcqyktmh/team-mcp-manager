配置前准备 · 网站扫码登录

登录管理器 → 云之家官方二维码 → 手机扫码确认 → 返回管理器。

官方扫码接入文档 ↗
查看扫码应用配置步骤
  1. 在云之家创建专门用于扫码登录的应用，取得它的 AppID 和 AppSecret；不要直接混用原工作台轻应用。
  2. 云之家扫码应用的「移动端访问地址」填写官方固定地址：https://www.yunzhijia.com/opencloud/openthird/qrlogin。
  3. 在下方填写扫码应用的 AppID、AppSecret、企业 eid。管理器的「扫码完成后的回调地址」填写公司 HTTPS 管理器域名加 /auth/cloud-home/entry，它和上一步的地址不同。
  4. 填写管理员账号、姓名和已核验手机号，先保存未启用的草稿。在服务器本机点击「准备扫码」，扫码后查看身份并确认绑定，系统自动保存 openid。随后启用登录、保存并重启。
  5. 员工直接打开管理器，点击「云之家扫码登录」，用云之家 App 扫码。扫码账号所在企业必须开通该扫码应用；回调后确认身份并进入对应员工账号。
二维码由云之家官方页面生成，不是演示二维码。管理器校验浏览器 state、一次性 ticket、应用和企业归属。账号密码登录只在企业提供正式网站 SSO 协议后对接，当前不在管理器收集云之家密码。

配置前准备 · 云之家轻应用

标准流程：工作台打开应用 → 校验一次性 ticket → 核对企业成员 → 确认登录。

官方轻应用指南 ↗
查看配置步骤与员工绑定说明
  1. 公司管理员登录云之家 Web 端，在「管理中心 → 轻应用管理」新建企业轻应用，取得 AppID 和 AppSecret，先限制为测试人员可见。
  2. 在下方选择「轻应用 ticket 免登」，填写企业团队 eid。令牌与身份接口已按官方文档内置，通常无需修改。
  3. 填写公司服务器 HTTPS 地址加 /auth/cloud-home/entry，并把相同地址登记为轻应用的移动端、Web 端或桌面端访问地址。
  4. 核验首位管理员在该企业的 openid，登记其管理器账号、姓名和手机号。普通员工需先在「用户与用户组」登记手机号，再点击「绑定云之家」录入企业 eid 和成员 openid。
  5. 保存后可检查应用凭据。确认信息完整再勾选启用，保存并重启管理器；从云之家工作台打开应用，用真实测试员工完成登录确认。
ticket 不可重复使用；系统仅信任服务端换取的企业身份，不把前端 getPersonInfo、姓名或 deviceId 当成身份或手机号。身份接口不保证返回手机号，手机号由企业管理员核验后登记。普通浏览器直达不是扫码登录，需要从云之家工作台进入。
