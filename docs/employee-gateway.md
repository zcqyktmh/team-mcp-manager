# 员工 MCP 网关

## 使用
1. 管理员配置并同步 MCP，启用服务并发布到公司市场。
2. 在权限策略中授予员工用户组或个人具体工具权限；明确 deny 优先，无授权默认拒绝。
3. 员工使用云之家登录，在“我的 MCP”绑定本人下游凭据。
4. 在“AI 工具连接”创建服务专属令牌，复制网关地址和 Bearer 令牌到客户端。令牌只显示一次，有效30天，可撤销。
5. 客户端使用 Streamable HTTP，设置 Authorization: Bearer <个人令牌>。不要把令牌写入共享仓库。

网关地址： https://管理器域名/gateway/<服务ID>/mcp
匿名开发预览不允许签发令牌。网页 Cookie 不作为网关认证。当前采用个人 Bearer 令牌，尚未实现 OAuth 浏览器授权。

## 执行边界
- 每次读取最新用户、市场发布状态、启用状态和工具权限；工具列表过滤和调用端同时检查。
- 管理员没有工具授权也不能通过网关执行工具。
- 每次使用调用员工自己的 Basic/Bearer 凭据，不使用管理员共享凭据。无认证下游不能保证数据源的员工身份。
- 下游会话按请求初始化，不跨用户共享，不自动重试写入。
- 仅开放 tools/list 和 tools/call；资源、提示词、服务端采样、长连接推送等不在当前支持范围内。
- 数据库行级权限、SQL语义校验、删除逐次审批须由受控工具和数据源权限执行，本版本未实现。
- 管理员可登记内网地址，因此生产环境必须限制管理员和服务器出站网络。
- 生产部署务必使用 HTTPS，并用防火墙限制下游 MCP 仅接受网关服务器连接。应用代码无法自动配置公司防火墙。
- 网关拒绝和调用结果写入后台日志，不记录令牌、下游凭据、工具参数和结果正文。

本次完成源代码与语法检查；尚未进行真实 AI 客户端和公司下游服务联调。
